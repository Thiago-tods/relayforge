# 12. Role-based access control

Date: 2026-11-17

## Status

Accepted

## Decision

Exactly four roles live on **memberships**: `OWNER`, `ADMIN`, `DEVELOPER`, `VIEWER`. A database check
constraint rejects any other value. Authorization is centralized in `internal/tenancy/role.go`;
handlers and services ask `tenancy.Can(role, permission)` and never compare role strings.

| Operation | OWNER | ADMIN | DEVELOPER | VIEWER |
|---|---|---|---|---|
| View organization | Yes | Yes | Yes | Yes |
| Update organization | Yes | Yes | No | No |
| List members | Yes | Yes | Yes | Yes |
| Invite members | Yes | Limited | No | No |
| List and revoke invitations | Yes | Yes | No | No |
| Change member roles | Yes | Limited | No | No |
| Remove members | Yes | Limited | No | No |
| Transfer ownership | Yes | No | No | No |
| View audit events | Yes | Yes | No | No |

**"Limited" means:** an ADMIN may act only on members who are currently DEVELOPER or VIEWER, and
may only assign DEVELOPER or VIEWER. An ADMIN can therefore never touch another ADMIN or the OWNER,
and can never create an ADMIN or OWNER (including by invitation). An OWNER may assign ADMIN,
DEVELOPER or VIEWER to anyone but the owner.

**Owner invariants.**

- Nobody assigns, demotes or removes OWNER through the regular endpoints (`409
  use_ownership_transfer` or `403`). The invitation table also rejects OWNER.
- A partial unique index allows at most one ACTIVE OWNER per organization.
- Ownership changes only through `POST .../transfer-ownership`: caller must be OWNER, target an
  active member other than the caller; the caller becomes ADMIN and the target OWNER in one
  transaction under the organization lock. Concurrent transfers serialize: exactly one wins and the
  others fail with `403` because they are no longer the owner.
- Nobody can change or remove their own membership (`409 cannot_modify_self`). Leaving an
  organization is deferred.

## Consequences

Adding a role or permission means editing one table and its tests. Table-driven tests cover every
actor, target and new-role combination.
